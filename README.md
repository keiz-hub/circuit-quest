# Circuit Quest v13 - Console Lock Fix

## Fix in this version
- Players can no longer answer questions or test puzzle repairs unless their character is physically beside the broken console.
- The mission panel can still show the objective, but it is locked with a clear message: “Go to the broken console to answer.”
- Clicking the console from far away no longer activates the mission.
- Players must move beside the BROKEN console and press Interact / Space, or click the console while close enough.

## Project type
Static front-end only. No database and no backend required. Suitable for GitHub Pages.
